## 🚀 Sobre el Proyecto

Portafolio personal creado para exhibir proyectos, certificaciones y habilidades técnicas de manera atractiva e interactiva. Desarrollado completamente con tecnologías web frontend, sin dependencias externas ni frameworks.

### 🎯 Objetivos

- Mostrar proyectos personales y profesionales
- Exhibir certificaciones obtenidas (incluyendo automatización con IA)
- Proporcionar una experiencia de usuario fluida y moderna
- Servir como carta de presentación digital

---

## ✨ Características

- 📱 **Diseño Responsive** — Adaptable a móviles, tablets y escritorio
- 🎨 **Interfaz Moderna** — Estilos personalizados con CSS3
- ⚡ **Interactividad** — Comportamiento dinámico con JavaScript vanilla
- 🏆 **Sección de Certificados** — Descripciones actualizadas de certificaciones
- 🖼️ **Galería de Imágenes** — Recursos visuales organizados
- 🔧 **Código Limpio** — Estructura modular y mantenible

## ⚙️ Instalación

### Prerrequisitos

- Un navegador web moderno (Chrome, Firefox, Edge, Safari)
- [Git](https://git-scm.com/) (opcional, para clonar el repositorio)

### Pasos

1. **Clona el repositorio**

   ```bash
   git clone https://github.com/GeanluisGL/Portfolio.git
   ```

2. **Accede al directorio**

   ```bash
   cd Portfolio
   ```

3. **Abre el proyecto**

   Simplemente abre el archivo `index.html` en tu navegador.

---

## 💻 Uso

### Opción 1: Abrir directamente

Haz doble clic en `index.html` o arrástralo a tu navegador.

### Opción 2: Live Server (Recomendado)

Si usas **VS Code**, instala la extensión **Live Server**:

1. Clic derecho sobre `index.html`
2. Selecciona **"Open with Live Server"**
3. Se abrirá en `http://127.0.0.1:5500`

### Opción 3: Servidor local con Python

```bash
# Python 3
python -m http.server 8000

# Python 2
python -m SimpleHTTPServer 8000
```

Luego visita `http://localhost:8000`

Las contribuciones son bienvenidas. Sigue estos pasos:

   ```bash
   git checkout -b feature/NuevaCaracteristica
   ```

